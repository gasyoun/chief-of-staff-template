# /brief — утренний бриф

Выполни в любом порядке, держи общий бюджет ~5 минут, читай хвосты и числа, не целые файлы.
Каждый пункт — с путем-пруфом. Ничего не отправляй.

1. **Контекст.** Прочитай `me/current-drive.md`, `me/weekly-goals.md`, `me/waiting-on.md`, `me/sources.md`.
   Понедельник — в топ брифа: подготовка к созвону в 13:00 (график после лета пляшет,
   владелец решает, состоится ли; статус на этой неделе см. в `me/log/`).
2. **Чат спринта** (`~/Documents/GitHub/sprint-watch/log.md`): новое с последней метки — анонсы,
   вердикты бота «принято +N», вопросы к владельцу. Дедлайны домашек — в топ брифа, если горят.
3. **GTD** (`~/Documents/GitHub/Uprava/GTD_BOARD.md`): WIP против капа, топ-3 протухших @DECIDE,
   failsweep-красное.
4. **Реестр** (`~/Documents/GitHub/Uprava/handoffs/README.md`): счет открытых 🟡 и новые строки
   с прошлой метки (метку храни в `me/log/` → секция «метки чтения»).
5. **Estate** (`~/Documents/GitHub/SecondBrain-LLM-Wiki/40-Estate/estate-dashboard.md`):
   stale-числа, что протухло с прошлой пробы.
6. **Флот и сеть**: `skills/fleet-check/SKILL.md` (мертвые лейны, просроченные heartbeat'ы,
   донесение ≤5 строк) + деградация VPN по `me/sources.md`. Понедельник — созвон 13:00 в топ.
7. **Флот-действия не входятся в бриф**: увидели мертвое — донесли; команды только через `/fleet-act`.

## Формат результата

Запиши `me/briefs/YYYY-MM-DD.md` (решения гриля 03-10 — секции 3–5 обязательны):

```
# Бриф DD-MM-YYYY
## Сегодня главное (≤3)
## СДЕЛАНО ФЛОТОМ ЗА 24Ч (закрытые юниты, артефакты, ремонты — не аптайм!)
## ПЛАН/ФАКТ ночной волны (минимум 5-10 юнитов — это ПОЛ, не план; недобор — красной строкой)
## Черновики напоминаний (waiting-on: готовый текст для копирования)
## Дедлайны недели (07-10 вечер: лист голосования H1685; 15-10: слоты рецензий)
## Решения, которые ждут
## Просроченные ожидания (waiting-on старше N дней)
## Новое за ночь (чат / GTD / реестр / estate)
## Прочитать позже
```

Дедлайны (решение гриля 03-10): к вечеру 07-10 собрать лист голосования на 08-10
(только spotcheck H1685, строка 0CZ, планка 0.80, одной волной) и держать в брифах
напоминание про раздачу слотов рецензий к 15-10.

Выход — два файла-слоя (решение гриля 03-10, вечер): `me/briefs/YYYY-MM-DD.md` (как выше —
полная выкладка, каждый пруф — ссылкой) и `me/briefs/YYYY-MM-DD.html` — eli5-слой для
браузера по шаблону `skills/brief/template.html` (шрифт Charis). Правила HTML-слоя:

- Табло дня: 3-4 карточки-цифры, каждая — ссылкой на пруф.
- Неделя: SVG-лента дедлайнов вместо текстовой секции «Дедлайны недели».
- Волна план/факт: SVG-шкала 0-10 юнитов; недобор — красным.
- Один пункт — одна строка; подпись картинки ≤15 слов; жаргон — глосса на месте.
- Каждый факт — ссылка-пруф: запушенное → полный blob URL, локальное → file://-путь;
  известной цели нет — ссылки нет, не выдумывать.
- Оба файла после заполнения — финальный проход sokratil (резать втрое).

В HTML-брифе фиксируй строку «собрано за N мин» — данные для честного замера
«полчаса в день» (обещано в посте задания2). Покажи владельцу табло + «Сегодня главное»;
остальное — в файлах. Источник недоступен — честная строка «источник недоступен», не «пусто».
